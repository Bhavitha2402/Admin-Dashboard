 
# 📊 Admin Dashboard

A responsive admin dashboard built with **React, TypeScript, Vite, and Tailwind CSS**, featuring reusable UI components and interactive data visualizations.

🌐 **Live Demo:** https://admin-dashboard-ten-murex-77.vercel.app

## ✨ Features

- 📊 Interactive dashboard
- 📈 Data visualization with Recharts
- 📱 Responsive layout
- 🧩 Reusable UI components
- 🧭 Client-side routing
- 📝 Form handling and validation
- 🔔 Toast notifications
- 🎨 Modern dashboard interface
- 🌓 Theme support

## 🛠️ Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### UI & Components
- Radix UI
- Lucide React
- Tailwind CSS utilities

### State & Forms
- TanStack Query
- React Hook Form
- Zod

### Data Visualization
- Recharts

### Routing
- React Router DOM
